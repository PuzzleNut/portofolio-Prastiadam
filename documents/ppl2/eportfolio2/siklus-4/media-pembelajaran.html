Apa itu Sistem Komputer?

Sistem Komputer adalah kumpulan perangkat-perangkat komputer yang saling berhubungan dan berinteraksi satu sama lain untuk melakukan proses pengolahan data sehingga menghasilkan informasi yang bermanfaat bagi penggunanya.

3 Komponen Utama (Trilogi Sistem)

Komputer tidak akan berfungsi jika salah satu dari ketiga komponen ini tidak ada.

Hardware

Perangkat Keras

Komponen fisik komputer yang dapat dilihat, disentuh, dan dipindahkan. Berfungsi sebagai "Tubuh" fisik komputer.

Software

Perangkat Lunak

Kumpulan instruksi dan program yang mengontrol kinerja hardware. Tidak dapat disentuh. Merupakan "Jiwa / Otak" komputer.

Brainware

Pengguna / Manusia

Manusia yang mengoperasikan, memberi perintah, dan mengelola komputer. Merupakan "Pengendali Utama" seluruh sistem.

💡 Analogi Sederhana:

Sebuah komputer canggih (Hardware) tidak akan bisa dinyalakan tanpa Sistem Operasi seperti Windows atau Linux (Software). Namun, meskipun komputer sudah menyala, sistem tidak akan menghasilkan apa pun tanpa adanya kamu (Brainware) yang memasukkan data atau perintah. Ketiganya wajib ada dan bekerja secara harmonis!

4 Jenis Perangkat Keras (Hardware)

Arahkan kursor (hover) pada setiap kartu di bawah untuk mempelajari fungsinya!

Input Device

Perangkat Masukan

Input Device

Perangkat yang digunakan untuk memasukkan perintah atau data mentah ke komputer.

CONTOH:

Keyboard, Mouse, Scanner, Microphone, Webcam, Touchscreen

Process Device

Perangkat Pemrosesan

Process Device

Pusat pengolah data yang mengeksekusi perhitungan dan logika instruksi.

CONTOH:

CPU / Processor (ALU & CU), VGA Card / GPU, Motherboard

Storage Device

Perangkat Penyimpanan

Storage Device

Menyimpan data baik secara sementara (Primary) maupun permanen (Secondary).

1. Utama (Sementara):

RAM & Cache (diakses langsung oleh CPU)

2. Sekunder (Permanen):

SSD, Harddisk (HDD), Flashdisk

Output Device

Perangkat Keluaran

Output Device

Menampilkan atau mengeluarkan hasil akhir data yang telah diproses oleh CPU.

CONTOH:

Monitor, Printer, Speaker, Headphone, Proyektor LCD

Waktunya Berlatih! 📝

Mari kita beri jeda sejenak. Silakan buka dan kerjakan LKPD (Lembar Kerja Peserta Didik). Analisis permasalahan studi kasus dan tentukan perangkat keras yang paling tepat sesuai fungsinya!

Status Kelas Pengerjaan LKPD
SIMULASI ALUR KERJA KOMPUTER

Siklus Kerja Komputer: Input → Process ↔ Storage → Process → Output

Data dimasukkan melalui Input, diolah oleh CPU (Process), disimpan/dipanggil ke Storage (RAM/Disk), lalu dikembalikan ke CPU untuk finalisasi sebelum dikirim ke Output.

1. INPUT Keyboard, Mouse, Suara
2 & 4. PROCESS CPU / Processor
Simpan & Panggil
3. STORAGE RAM & SSD/HDD
5. OUTPUT Layar, Printer, Speaker

Klik salah satu tombol langkah di atas untuk mensimulasikan alur perjalanan data dari awal hingga menghasilkan informasi.
